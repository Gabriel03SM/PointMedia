# POINT MEDIA — DESIGN SYSTEM E IDENTIDADE VISUAL

## 1. Princípio geral

A interface do sistema deve utilizar a identidade visual da Point Media como referência principal.

O design deve transmitir:

* modernidade;
* criatividade;
* tecnologia;
* movimento;
* profissionalismo;
* simplicidade.

A interface deve evitar aparência excessivamente corporativa, genérica ou semelhante a sistemas administrativos tradicionais.

A identidade visual deve estar presente principalmente em:

* login;
* dashboards;
* cabeçalhos;
* botões;
* cards;
* formulários;
* estados visuais;
* elementos decorativos;
* páginas públicas;
* banco de talentos;
* processo seletivo.

---

# 2. Logo

A marca utiliza o wordmark:

**point**

Características:

* escrita em letras minúsculas;
* fonte sans-serif geométrica;
* peso bold;
* cor preta.

O caractere **"o"** é substituído por um círculo duotone:

* base rosa/magenta;
* ícone de play triangular azul centralizado.

O símbolo representa:

* mídia;
* vídeo;
* movimento;
* comunicação;
* criatividade.

## Símbolo isolado

O círculo rosa com play azul poderá ser utilizado isoladamente em:

* favicon;
* ícones;
* rodapés;
* elementos de navegação;
* carregamento;
* identificadores compactos da marca.

## Regra

Não modificar a proporção ou estrutura da marca.

Não utilizar efeitos desnecessários, como:

* sombras excessivas;
* glow exagerado;
* gradientes fora da identidade;
* distorções;
* rotações;
* efeitos 3D.

---

# 3. Paleta de cores

## Azul primário

Utilizado principalmente em:

* fundos de seção;
* destaques;
* elementos informativos;
* gráficos;
* estados selecionados;
* elementos de navegação.

Referência:

```text
#5B9BD5
#6FA8DC
```

O valor definitivo poderá ser centralizado em uma variável de design.

---

## Rosa / Magenta

Utilizado principalmente em:

* CTAs;
* botões;
* links de destaque;
* bordas;
* indicadores;
* elementos decorativos;
* símbolo da logo.

Referência:

```text
#E91E8C
#EC4899
```

---

## Preto

Utilizado principalmente em:

* títulos;
* textos principais;
* ícones;
* navegação;
* elementos de alta prioridade;
* ícones sociais.

Referência:

```text
#000000
#111111
```

---

## Branco

Utilizado principalmente em:

* fundo;
* áreas de respiro;
* cards;
* formulários;
* contraste com elementos coloridos.

Referência:

```text
#FFFFFF
```

---

# 4. Uso das cores

A interface não deve utilizar todas as cores com a mesma intensidade.

Hierarquia recomendada:

```text
Preto
↓
Branco
↓
Azul
↓
Rosa
```

O rosa deve ser utilizado principalmente para chamar atenção para ações importantes.

Exemplo:

```text
[ Candidatar-se ]
```

O botão principal deverá utilizar rosa com texto branco.

O azul deverá funcionar principalmente como cor estrutural e de destaque.

O preto deverá permanecer como principal cor tipográfica.

---

# 5. Tipografia

## Títulos

Os títulos devem utilizar uma fonte sans-serif pesada e geométrica.

Referência visual:

**Syne**

Características:

* peso elevado;
* formas geométricas;
* aparência contemporânea;
* preferência por caixa baixa;
* forte presença visual.

Exemplo:

```text
encontre seu próximo talento
```

---

## Corpo

O texto deverá utilizar uma fonte sans-serif mais neutra e legível.

Referência:

**DM Sans**

Características:

* boa legibilidade;
* peso regular;
* espaçamento confortável;
* adequada para interfaces.

---

## Hierarquia

A hierarquia visual deverá ser construída principalmente através de:

* tamanho;
* peso;
* espaçamento;
* posição.

Não utilizar cores diferentes em excesso para criar hierarquia.

---

# 6. Elementos decorativos

## Linha de círculos

Um elemento recorrente da identidade é uma sequência de pequenos círculos.

Exemplo conceitual:

```text
○ ● ○ ● ○ ● ○ ● ○
```

Os círculos devem alternar entre:

* rosa;
* azul.

Podem ser utilizados em:

* topo de seção;
* rodapé;
* divisores;
* cabeçalhos;
* áreas de transição.

Esse elemento funciona como uma assinatura visual da marca.

Não utilizar em excesso.

---

# 7. Linhas curvas

Podem ser utilizadas linhas curvas soltas semelhantes a rabiscos desenhados à mão.

Características:

* traço simples;
* aparência orgânica;
* rosa ou azul;
* baixa interferência visual.

Devem ser utilizadas para quebrar a rigidez do grid.

Locais recomendados:

* cantos;
* fundos;
* áreas vazias;
* transições entre seções.

Não devem prejudicar:

* leitura;
* acessibilidade;
* navegação;
* formulários.

---

# 8. Fotografia

Quando fotografias forem utilizadas, priorizar:

* preto e branco;
* alto contraste controlado;
* composição limpa.

Fotos de pessoas, como integrantes da equipe ou candidatos quando apropriado, podem ser apresentadas dentro de círculos.

O círculo poderá utilizar uma borda em gradiente:

```text
rosa → azul
```

A fotografia deve permanecer visualmente limpa.

Evitar filtros excessivos.

---

# 9. Botões

Os botões principais devem seguir o formato **pill**.

Características:

* bordas altamente arredondadas;
* preenchimento rosa;
* texto branco;
* peso médio ou semibold;
* área de clique confortável.

Exemplo:

```text
╭────────────────────╮
│    candidatar-se   │
╰────────────────────╯
```

Botões secundários podem utilizar:

* fundo branco;
* borda preta;
* borda azul;
* texto preto.

---

# 10. Ícones

Os ícones devem possuir aparência simples e consistente.

Priorizar:

* ícones lineares;
* espessura consistente;
* formas geométricas;
* boa legibilidade.

Ícones sociais devem utilizar:

* círculo preto preenchido;
* ícone branco centralizado.

---

# 11. Cards

Cards deverão possuir visual moderno e limpo.

Características recomendadas:

* fundo branco;
* bordas suaves;
* cantos arredondados;
* espaçamento interno adequado;
* sombra extremamente discreta ou inexistente;
* destaque por tipografia e estrutura.

Evitar excesso de:

* sombras;
* gradientes;
* bordas coloridas;
* efeitos de vidro;
* elementos decorativos.

---

# 12. Formulários

O formulário de candidatura é uma das áreas mais importantes do sistema.

A prioridade deve ser:

1. clareza;
2. acessibilidade;
3. simplicidade;
4. velocidade de preenchimento;
5. feedback visual.

Cada campo deverá possuir:

* label visível;
* descrição quando necessária;
* indicação de obrigatoriedade;
* estado de foco;
* estado de erro;
* mensagem de erro clara.

Evitar placeholders como substitutos dos labels.

---

# 13. Dashboard do RH

O dashboard deverá combinar a identidade Point Media com informações densas de maneira organizada.

Deve utilizar:

* cards de indicadores;
* tabelas;
* gráficos;
* filtros;
* ranking;
* status;
* indicadores visuais.

O design deve evitar transformar o dashboard em uma interface excessivamente colorida.

O rosa deve destacar ações e informações prioritárias.

O azul deve estruturar informações e estados.

---

# 14. Ranking de candidatos

O ranking é uma funcionalidade central do sistema.

A interface deve destacar:

* posição;
* candidato;
* percentual de compatibilidade;
* requisitos atendidos;
* requisitos não atendidos;
* tecnologias compatíveis;
* senioridade;
* pretensão salarial;
* status no processo seletivo.

O percentual de compatibilidade deve possuir forte destaque visual.

Exemplo:

```text
#01   Gabriel Freitas

      Desenvolvedor Full Stack

      Compatibilidade
      ████████████████  92%

      ✓ React
      ✓ NestJS
      ✓ TypeScript
      ✓ Node.js
      ⚠ Pretensão salarial
```

A representação final deverá ser definida de acordo com o design system.

---

# 15. Responsividade

O sistema deverá ser responsivo.

Deve funcionar adequadamente em:

* desktop;
* notebook;
* tablet;
* smartphone.

A experiência mobile não deve ser simplesmente uma versão reduzida do desktop.

Elementos como:

* tabelas;
* dashboards;
* filtros;
* menus;
* cards;

deverão possuir comportamento específico para telas menores.

---

# 16. Acessibilidade visual

A identidade visual não deve comprometer a acessibilidade.

Garantir:

* contraste adequado;
* foco visível;
* tamanho de fonte adequado;
* áreas de clique suficientes;
* não depender somente de cores para indicar estados;
* compatibilidade com navegação por teclado;
* textos alternativos quando necessário.

Rosa, azul e preto não devem ser utilizados como única forma de diferenciar estados.

Exemplo:

```text
✓ Aprovado
⚠ Em análise
✕ Reprovado
```

Além da cor, utilizar texto e/ou ícones.

---

# 17. Regras para o desenvolvimento

O desenvolvedor deverá criar um pequeno **Design System** antes de espalhar estilos pelo projeto.

Centralizar:

* cores;
* tipografia;
* espaçamentos;
* border radius;
* sombras;
* tamanhos;
* estados;
* componentes reutilizáveis.

No React, componentes recorrentes deverão ser reutilizados.

Exemplos:

```text
Button
Input
Select
Card
Badge
Modal
Table
Avatar
Progress
Navbar
Sidebar
```

Evitar duplicação de estilos.

---

# 18. Regra de fidelidade visual

Sempre que houver conflito entre uma decisão estética genérica e esta identidade visual, priorizar a identidade da Point Media.

A interface não deve parecer um template administrativo genérico.

O resultado deve transmitir uma identidade própria, mantendo:

**Point Media = tecnologia + criatividade + mídia + simplicidade.**
